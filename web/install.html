📱iPhone / iPad

⬇︎ Download install profile

Open this page in Safari to install the profile.

  1. Tap the button above — Safari will say the profile was downloaded.
  2. Open Settings → Profile Downloaded → Install (top right).
  3. Enter your passcode, tap Install again, then Done.
  4. The icon is now on your Home Screen.
iOS will show “Unverified” — the profile is unsigned. It only adds a Home Screen icon; it changes no other setting.

Or without a profile: Share ⬆︎ → Add to Home Screen.
